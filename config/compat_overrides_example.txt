# Example override file for compatibility patches: build-compat.py --overrides <this file>
#
# Overrides are optional: without them, the files both mods contain are patched exactly as the
# Smooth UI Remastered release was (as recorded in its manifest). Most mods need nothing more.
#
# The syntax is that of config/profile_default.txt (see it for the settings and patterns), except:
#   - There are no [N] sections. A file line refers to a file that both mods contain; it doesn't
#     add one. To change a file's frame rate, use "fps:" under it.
#   - Settings are added to the release's: fps replaces its frame rate, retime lines are tried
#     before its retime lines, and include/exclude/fix lines are added to its lists. Settings from
#     the release can't be removed.
#   - "sprite N" refers to sprite ids in the other mod's version of the file.
#   - Warnings that the other mod's changes introduce must be checked by hand. Once they are, mark
#     them as reviewed under * (the build prints the lines to add).
#
# Example (uncommented, this would apply to the files listed):
#
#   *
#       exclude: ^OtherMod_
#       reviewed: unresolved-goto OtherModPanel.updateIcon @1a2b3c4d
#
#   gameplay/gui_new/swf/inventory/panel_inventory.redswf
#       fps: 60
#       include: ^OtherMod_SlotGlow$
#       exclude: sprite 1234
